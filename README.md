# subs

Clean, tested proxy subscription generated by subs-check from ProxyNodeHub sources.

- `all.yaml` — Clash format, 200 tested nodes
- `mihomo.yaml` — Mihomo/Clash with routing rules
- `base64.txt` — Base64 subscription for v2rayN and similar clients

Source: ProxyNodeHub discovery on Instabox, filtered by subs-check (alive + speed test).
Updated automatically every 2 hours when the Instabox machine is running.

Free public nodes only — untrusted third-party endpoints, for testing only.
